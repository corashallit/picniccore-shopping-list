# Concept renders

Painted concepts made with `gpt-image-2` while choosing the art direction. They are references, not production assets.

| File | Direction |
|---|---|
| `a_list.jpg`, `a_icons.jpg` | A · Strawberry Matinee ("Gingham Star!"): 1993 Saturday-morning cel cartoon of a strawberry picnic |
| `b_list.jpg`, `b_icons.jpg` | B · Firefly Moon Picnic ("Firefly Hamper"): Art Nouveau full-moon picnic, groceries as enamel charms |
| `c_list.jpg`, `c_icons.jpg` | C · Furoku Sticker Album ("Kirakira Basket"): 1994 manga-magazine letter set and puffy sticker sheet |
| `concepts_overview.jpg` | All three side by side |
| `a_list_sunburst.jpg`, `b_list_sunburst.jpg`, `c_list_sunburst.jpg`, `concepts_overview_2_5.jpg` | The same list screens re-rendered with `gpt-image-2.5-sunburst` |
| `icons_model_compare.jpg` | Each direction's icon sheet from `gpt-image-2`, `gpt-image-2.5-flare` and `gpt-image-2.5-sunburst` |

Each list screen shows collapsed aisles drawn as little baskets holding mini item icons.

The app draws icons with `gpt-image-2.5-flare`. `gpt-image-2` can't produce real transparency, so it isn't used for icons.
